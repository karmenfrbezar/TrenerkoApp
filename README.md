# TrenerkoApp
## Projekt za kolegij Programsko inženjerstvo

Trenerko je web aplikacija razvijena korištenjem Quasar Frameworka, Vue.js, Node.js, Express.js i MySQL baze podataka. Cilj aplikacije je povezati sportaše, vlasnike sportskih objekata i organizatore događaja kroz jedinstvenu platformu za pretraživanje sportskih sadržaja, upravljanje objektima i sudjelovanje u sportskim aktivnostima.

### Glavne funkcionalnosti
- Registracija i prijava korisnika
- Upravljanje korisničkim profilom
- Pregled sportskih objekata na interaktivnoj karti 
- Dodavanje, uređivanje i brisanje sportskih objekata
- Organizacija i pregled sportskih događaja
- Dodavanje recenzija i ocjenjivanje objekata
- Sustav favorita za spremanje omiljenih objekata
- Pretraživanje i filtriranje sportskih sadržaja

### Tehnologije

Frontend
- Vue 3
- Quasar Framework
- Leaflet
- JavaScript
- HTML/CSS

Backend
- Node.js
- Express.js
- REST API

Baza podataka
- MySQL
